# Install plugins

Plugins come with Mumcord 0.6.0. Nothing is preinstalled: you choose what you want.

## Install a plugin

1. Open **Settings → Plugins → Browse** in Mumcord.
2. Pick a plugin and read its permissions.
3. Choose **Install**.

Its icon appears in the **plugins strip** under the channel tree. Select it to open the plugin.

> [!TIP]
> Plugins only talk to the same plugin of other Mumcord users in your channel. Your friends see
> polls, dice cards and pets when they install the same plugin. Everyone else sees a plain text
> line where it matters.

## Updates

Updates install by themselves when they need no new permissions. An update that asks for more
permissions waits until you approve it.

## Turn plugins off

- **One plugin:** turn it off or uninstall it in **Settings → Plugins**.
- **All plugins at once:** choose **Turn off all plugins** in **Settings → Plugins**, or open the
  command palette with ++ctrl+shift+p++ and run it from there.

## Optional permissions

Some permissions are optional. You can switch them off before installing or at any time later in
**Settings → Plugins**. The plugin keeps working with what is left. See
[Permissions explained](permissions-explained.md).

## Other plugin repositories

Besides the official registry, anyone can run their own plugin repository. You add one in
**Settings → Plugins**. Plugins from other repositories are marked **Unofficial**, and a few
powerful permissions are only available to official plugins. See [Safety model](safety.md).

## Languages

Plugins are available in all 24 Mumcord languages.
